## Project name

Use **Span** when referring to the project and `span` for the CLI binary. MCP
tool names use the `span_` prefix. When distributing a fork, identify it as a fork
and avoid implying endorsement by the upstream project. This guidance adds no
conditions to the software license.

## Attribution

Preserve applicable copyright and license notices when redistributing the
software. Follow Apache-2.0 §4 for modification notices and attribution. See
[NOTICE](NOTICE) for project attribution and [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)
for dependency and model notices.
